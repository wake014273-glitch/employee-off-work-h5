# 参考视频第三种拖尾

参考用户提供的本地视频「微信视频2026-10-14_033819_695.mp4」，第三行标注为「粒子效果 / Particular Effect」。可见形态是一条连续、圆头、弯曲的拖尾，越接近尾端越细、越透明。

猫猫移动拖尾已替换为这个形态。采用薄荷青主体、奶油白窄高光与淡紫尾端，配色对应地板和蓄力条的青色、UI 的奶油底和紫色描边；护盾期间主体转为奶油金，与已有免疫轮廓协调。光带绘制在角色身后，不覆盖角色表情和头顶进度条。

每 4 个设计像素采样真实移动路径，固定复用 48 个粒子位置。快速拖动时补足中间采样，防止光带断成点；路径经过两轮圆滑处理，再绘制柔边、主体和高光。圆头半径 18 个设计像素，尾端宽度与透明度同时递减；从脚部接出，避免身体挡住整条尾迹。最长保留 180 个设计像素的已走路径，停下约 0.48 秒完全淡出。转向和上下移动均保留真实曲线，暂停冻结，重开、返回首页或跳转时清空。角色移动、弹簧、碰撞与 3 秒护盾时间沿用原有逻辑。

实现文件：`employee-off-work/assets/scripts/model/PlayerTrail.ts`、`assets/scripts/GameMain.ts`。单元检查覆盖快速拖动的连续采样、暂停与消散、瞬移清理、弯曲与反向、路径长度限制及静止抖动；浏览器和微信回归检查运行中的光带渲染、圆头与透明尖尾、游戏配色、角色后方层级及原有护盾效果。
