# 合并实战教程（2026-10-13）

移动、躲避工作任务和拾取小鱼在同一段练习中完成。取消原来约两秒移动考核和独立的拾鱼阶段，只拾取一条教程鱼即可完成。

## 玩家流程

1. 首次显示「成为摸鱼大侠之前先来熟悉一下基础操作吧」，说明拖动躲任务、摸鱼越久分数越高、捡鱼蓄护盾。点击「开始练习」进入练习；之前场景冻结。
2. 练习开始已有上方中央的一条绿色特效小鱼和三个紫色需求表。需求表横向移动、改变方向，并在练习区域边界折返；玩家停留时不会逐渐离场或额外增殖。
3. 下方显示「躲开需求表，去捡小鱼！」与两行操作说明。猫猫周围的方向箭头、手势和小鱼高亮同时显示，分别指明操作对象与目标。
4. 碰到需求表时猫猫与阴影同步闪烁，提示「试着从旁边绕过去」，说明正式游戏碰到三次任务就结束。练习不扣工作负荷，不计正式时长、分数、擦弹或甩脱奖励，也不会失败；反馈有 0.75 秒保护，避免连续刷提示。
5. 拾到小鱼增加一格蓄力，显示「Good！边躲边捡，学会啦！」、星光、跳跃和成功音。短暂庆祝后进入完成卡，说明五条鱼蓄满、双击屏幕或点击头像释放三秒护盾、躲避任务及正式受伤规则。
6. 点击「开始摸鱼！」进入正式第 1 波，保留教程鱼带来的一格蓄力。原有难度曲线和首次满盾提醒继续生效。

## 状态与实现

- 状态：`intro → practice → collect-reward → ready → off`。没有单独移动计时或第二阶段等待。
- Intro、奖励和完成卡期间，角色操作与练习弹幕冻结；Practice 期间角色和三颗弹幕持续运动，正式计时与生成器冻结。
- 教程版本提升到 3，已完成旧版教学的用户再次进入会看新版一次，个人纪录、音效偏好与既有存档保留。首页可以重播教学，练习可跳过。
- 在 `GameModel.setupPractice()` 建立练习场；工作弹幕仍集中更新并复用现有渲染对象池。反馈事件经控制器处理，没有直接调用微信能力或改动场景、Prefab、资源元数据。
- 桌面鼠标、手机触摸拖动和键盘确认共用相同流程。
