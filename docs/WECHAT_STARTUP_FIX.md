# 微信扫码停在 Cocos 标志页：启动修复（2026-10-13）

## 原因与复现

用户确认扫码停在 Cocos 引擎标志页，尚未进入游戏。此前的构建兼容补丁在 web-adapter 执行前保存了 GameGlobal.document。真实手机首次启动时该值为空，适配器随后才创建 document；其 Canvas 监听与微信触控回调仍引用旧的局部变量，触控初始化因此抛出 addEventListener 异常，启动 Promise 退出，画面停在 Cocos 标志页。

开发者工具预先提供 document，因此原先的模拟器回归没有覆盖这个差异。使用实际生成的 web-adapter 配合全新 iOS／Android 全局环境已复现同一个异常；将 document 绑定移到适配器执行完毕后，两种环境均能正常发送 touchstart、touchmove、touchend、touchcancel。

## 修改

- 构建脚本统一调用 scripts/wechat-runtime.mjs，先声明 document，完成适配器初始化后再绑定 GameGlobal.document。兼容旧补丁，重复处理保持幂等。
- 每次微信构建都执行实际生成适配器的 iOS、Android、开发者工具环境检查，失败则不报告构建成功。
- 美术分包只有一个关键加载入口。资源增加有界重试、超时和进度；图片同时解码最多两张。已加载资源保留，重试不会重复切分猫猫图集。
- 音效在关键画面资源完成后加载，不再提前发起第二次美术分包请求。音效不阻塞进入游戏。
- 资源最终失败时显示“重新加载”和“没连上办公室，点一下再试试～”，按钮在未就绪阶段也能接收点击，成功后恢复正常开局。
