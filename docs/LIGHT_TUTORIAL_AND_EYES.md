# 单条鱼教程、首次蓄满提示与弹幕眼神

日期：2026-10-12。按用户反馈简化现有体验，不改变连续波次、身体碰撞或护盾时长。

后续教程已按用户确认的设计改为正式开局前的两步练习，本文的单条鱼教程为历史记录。当前流程及顶部移动边界见 `TWO_STEP_TUTORIAL.md`；本文中的满格消耗、同步阴影和弹幕眼神继续沿用。

## 当前行为

- 首次开局只显示「拖动屏幕移动角色」与「拾取绿色小鱼，集满五格可获得护盾」。附近生成一条教程鱼；移动没有单独的检查步骤。拾取这条鱼即保存教程完成、隐藏提示并开始正式计时与弹幕，保留 20 能量／第一格。拾取前继续保持练习保护，也可以跳过。首页「操作教学」可重学。
- 后续正式游玩收集到总计五格时，显示六秒「双击屏幕开启护盾，保护自己 3 秒」提示。游戏继续运行，不需要为了继续游玩而完成放盾。使用护盾立即收起提示；首次提示状态保存到本机，避免额外拾鱼或下局反复提示。重放操作教学时允许重新提醒。头像单击、第二指点头像及桌面空格仍可放盾。
- 满格时恢复消耗碰到的小鱼，能量仍封顶 100。超额鱼只给普通拾取反馈，不再次播放蓄满音或制造蓄力飞光。护盾期间仍不拾鱼。
- 猫猫与脚下阴影共用同一套可见性，受伤／无敌闪烁时同步显示和隐藏；暂停时闪烁状态冻结。
- 工作弹幕沿用确认版 PNG：只在原深色眼睛内部覆盖旧亮点并绘制动态瞳孔。瞳孔略微朝向猫猫，亮点呈坏笑式新月，三类弹幕错开眯眼；红消息追踪时眯得更明显。眼神继承弹幕移动、缩放与转向，暂停时冻结，复用现有弹幕精灵与眼神节点；没有为弹幕添加独立逻辑 `update()`，没有改写原 PNG。

## 数据与实现

`TutorialGuide` 只保留拾取状态；`ShieldCoach` 单独管理不阻塞游戏的蓄满提示。`PlayerProgress` 在现有版本 1 存储中追加 `shieldHintSeen`，旧记录默认未提醒，教程完成、音效及个人纪录保留。游戏规则中的 `pickup.gained` 区分真正增加能量与满格消耗。

主要修改位于 `GameExperience.ts`、`GameModel.ts`、`GameMain.ts`、`GameInterface.ts` 和 `PlatformServices.ts`。场景、Prefab、UUID、确认版美术和微信服务隔离规则保持由 Creator 及现有平台层维护。
