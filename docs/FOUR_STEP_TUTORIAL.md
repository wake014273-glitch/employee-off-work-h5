# 四步教程（版本 6）

教程目标：让玩家依次完成躲避、拾鱼充能、双击免疫、Agent 减负，当前目标以 `1/4` 至 `4/4` 展示。正式游戏规则保持不变。

## 流程

1. 开场确认后开始练习，初始工作负荷 2 格、护盾充能 4 格。附近有三枚缓慢接近的需求表，没有小鱼或工具。玩家实际移动并避开本轮弹幕后显示「躲得漂亮！」。碰撞会将负荷加到 3 格，显示失败原因并在两秒后重试本步骤；不生成正式结算、不影响纪录。
2. 躲避反馈结束后生成一条发光小鱼，动态虚线从角色指向小鱼，目标外围有呼吸圆环。实际拾取后充满第五格，显示「GOOD!」。
3. 充满后显示虚拟手指和两次点击的循环动画。文案说明松手双击可获得 3 秒免疫。实际双击成功后隐藏手指，显示「太棒啦！」，角色下方显示无边框金色描边文字「免疫已开启」，随角色移动，免疫结束即隐藏；正式对局也采用相同提示，暂停或结算时隐藏。免疫计时同时继续。额外的需求表经过角色，展示挡伤效果；随后提示正在免疫，等待结束。
4. 免疫计时真正归零后，Agent 从角色另一侧的屏幕外围飞入并停留。虚线指向 Agent，明确说明降低 2 格工作负荷。实际拾取后负荷由 2 清到 0，显示「你学会啦！」。
5. 完成页显示实际减负结果，等待确认。只有确认才写入教程版本 6 和免疫教学完成标记；正式开局重置负荷、充能、免疫、计时和练习资源。

## 时序与表现

- 小鱼和 Agent 按阶段生成，避免提前拾取或同时出现多个教学目标。
- 单纯等待不能跳过躲避、拾鱼、双击或 Agent 拾取。夸奖动画结束才进入下一目标。
- 双击后的夸奖不会冻结免疫计时。暂停、倒计时和切到后台仍然冻结教程及免疫计时。
- 练习不累计时长、分数、连击、正式局数。旧版玩家保留最高分和设置，会重新学习新版教程；首页「操作教学」可重播。
- 虚线与手指使用运行时矢量绘制，不截获输入，也不需要新增 Cocos 场景、Prefab 或美术资源 UUID。

## 视觉细节优化（2026-10-16）

- 拾取路线改为柔和曲线，奶油白描边搭配金色圆角虚线，沿目标方向流动；角色周围与道具外围留出空隙，末端圆角箭头指向目标。
- 小鱼与 Agent 使用双层呼吸光圈和四个细小闪光，中心保持透明，避免遮住图标与翅膀。工具尚未进入画面时，引导停留在对应边缘。
- 双击手指改为带掌部、关节、柔和阴影与蓝色袖口的矢量造型，连续点按两次后停顿，触点波纹固定在指尖接触的位置。
- 手指进入步骤时选取角色侧上方的空位；动画期间保持位置稳定，角色靠近或屏幕尺寸变化时重新避让。字幕与扩散波纹均计入边界，避开顶部 HUD、角色和底部提示条。
- 步骤提示条采用轻量奶油色纸条、圆角金边、轻阴影和细分隔线，保持统一标题、正文与边距。夸奖仍为无边框文字，不改变四步教程逻辑或存档版本。

视觉优化后的实际截图与验证结果位于 `美术/界面风格统一/教程细节优化版/教程预览.html`。

## 验证入口

- `npm test`、`npm run test:soak`、`npm run qa`
- `node scripts/qa-office-ui.mjs --tutorial-flow`：实际 Web 指针输入，控制阶段时序便于核对画面。
- `node scripts/qa-office-ui.mjs --wechat --tutorial-flow`：微信原生拖动、点击；双击通过一次控制器调用避免 CLI 延迟拆散手势。报告明确记录输入方式。
- `npm run build:web`、`npm run build:wechat`：按 Finished 日志和产物存在判定成功。

实际画面位于 `美术/界面风格统一/四步教程版/教程预览.html`。
