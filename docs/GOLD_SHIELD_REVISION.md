# 护盾与设置按钮调整

这份文档记录上一版表现；当前青蓝护盾条、更亮金光、淡紫齿轮和移动拖尾见 [最新调整](BRIGHT_SHIELD_AND_TRAILS.md)。

采用用户选择的 B 方案：猫猫身体外侧显示奶油金柔光轮廓，每 1.5 秒完成一轮缓慢呼吸。不显示移动残影；轮廓使用猫猫当前动画帧的透明度遮罩，水平镜像和弹簧形变与角色保持一致，身体和表情保持原色。

角色头顶五格蓄力条在普通拾取时仍逐格变青蓝色。护盾开启后改为满条奶油金，再按剩余护盾时间从右向左连续退空；原来的 3 秒免疫时长保持一致，空条和金色轮廓消失发生在免疫结束的同一帧。暂停、设置面板和恢复倒计时期间均冻结护盾时间。

删除角色下方的「免疫就绪」「免疫中」横幅和护盾开启文字提示。首次满格也不再显示底部强制免疫提示，不暂停任务、不打断当前拖动；满格的金色蓄力条保留提示作用，双击屏幕或点击右上头像开启免疫。

设置按钮改成六齿圆角齿轮，采用现有 UI 的梅紫描边、暖金填色、奶油高光和下沿阴影，保留原有手绘圆框与设置面板。

主要文件：`FinalArtHud.ts` 负责五格填充与齿轮，`GameMain.ts` 负责动画轮廓和提示，`GameModel.ts` 中的 `SHIELD_DURATION` 是倒计时与免疫的共同来源。`immunity-silhouette.effect` 将图集 RGB 替换为金色，只保留透明轮廓；资源元数据由 Creator 构建时生成。

回归通过实际运行中的 Graphics 路径检查金色填充末端，覆盖完整、2.95 秒、1.5 秒和结束时的显示；同时检查暂停、免疫结束后的受伤判定、轮廓材质、呼吸变化、教程、设置及移动。
