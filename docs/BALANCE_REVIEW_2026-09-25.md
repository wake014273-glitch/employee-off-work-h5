## 1. 漏洞枚举

### A 无预警必死
- A1 出生贴脸即锁：玩家 y>h−200 且消息出生点同侧 200px 内 → 出生瞬间入 230 圈；最坏 0.49s 反应窗。
- A2 角落钉死：贴角 + ≥2 红同向 + 无盾；1.0s 无敌结束即再挨，workload 连吃到 3。
- A3 墙缝高压帧：墙扫过 ±0.6s 内红进 230；贴边带仅 36px（每侧 18px），规避=丢判定，挤出=吃撞。
- A4 三源同步：多源叠加，无敌 1.0s 间隙被连续兑现 → 约 10s 内 3 次命中=死。

### B 堵死
- B1 双墙错位：后期墙穿越 8.6s > 间隔 5.2s → 恒 ~1.66 面同场；错位最大 576px，需 ≥110px/s 横移 + 躲紫弹。
- B2 贴边缺口+伏击：缺口可落 0.1~0.9 任意处，贴边缺口无绕行空间。
- B3 资源堵死：workload 2/3 + 无盾 + ≥3 红围合 = 无 i-frame 冗余，数学无解。

### C 无限刷分
- C1 甩脱循环农场：230–260 环带进出，周期≈2.26s/颗；4 颗并行+爆发 S 链 ≈150–210/s（被动 20/s）。
- C2 倍率底薪：3s 内任一擦弹保持 combo；紫弹慢易贴，倍率常驻 1.8–2.0×。
- C3 清屏密度红利：后期 40–70 对象 → 单次 +400~700；期望 +2.4/s。
- C4 抽奖式重开：局外无代价（低危，暂不处理）。

### D 后期崩坏
- D1 曲线饱和：速度 5min、缺口 5min、墙 5.4min、同屏 8min、需求 11.6min、消息 13.8min → 第 14 分钟后不再变难（波次系数 3.0 封顶于 wave 23）。
- D2 追击团糊化：消息稳态 ≈11.9 颗，红无分离力，总对象 ≈17 挤在 652×1006 → 糊团+顺手甩脱变简单。
- D3 评分通胀：甩脱链 150–210/s，10 分钟 +10 万+；S 门槛 4 分钟即破。
- D4 目标缺失：14 分钟后无新机制。

## 2. 选定系统与三方向改进（风险换分系统）

### 预判
- P1 连击预告环：身周 68px；6/10/15 刻度 + 3s 保持条；掉链前 0.8s 变灰闪。边界：只显示已发生连击。
- P2 甩脱窗口卡：HUD 显示爆发窗 + N/4。边界：仅本窗已 ≥1 次甩脱后显示。
- P3 轨迹预演：combo≥15 对 homing 中红弹画 0.5s 虚线（1px/35%/≤400px）。边界：巡航态不画。

### 容错
- T1 连击保险丝：combo≥8 掉链只掉 50%；combo≥15 被撞保留 50% + 1.5s 豁免。边界：每 20s 一次；workload 惩罚不变。
- T2 近失补偿：甩脱窗改末次甩脱+2.6s；穿缝连击改末次穿缝+12s。边界：单次刷新≤+0.4s（总窗≤4.2s）；补偿不计门槛。
- T3 擦弹带反向加宽：combo≥10 → 41–58；combo≥15 → 41–64。边界：撞判定半径不变。

### 风险收益
- R1 贴脸档：41–45px 区 +2 连击层。边界：不直接加分。
- R2 兑现制：连击收益进未兑现池（4+0.4×combo/s）；兑现点=穿缝/甩脱各 50%；被撞损 50%、掉链损 30%。边界：池上限 3000。
- R3 评级预算制：每波每档限额 2 次，超出只显评级不加分。边界：超限仍 +1 连击层。

### 闭环对照
C1→R2+R3；C2→R1；C3→并入兑现池；D3→R3；D4→P1/P2；A1/A2 致死链→T1 缓解。
**不治（下一轮候选）**：A3/A4、B 全部（移动/技能系统）；D1/D2（难度系统第二曲线、红弹分离力）。
