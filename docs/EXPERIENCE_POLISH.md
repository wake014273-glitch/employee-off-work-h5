# 分步引导、头像护盾、音效与成绩单

日期：2026-10-12。项目 `employee-off-work`，Cocos Creator 3.8.8。沿用确认版背景、角色、弹幕、咸鱼与 HUD；没有修改原始 PNG、场景或 Prefab。新增资源由 Creator 导入并生成元数据。

后续调整：原三步教程已替换为单条鱼教程，首次满格改为游玩中提示双击放盾，最新说明见 `LIGHT_TUTORIAL_AND_EYES.md`。以下保留初次体验流程的实施记录。

## 本次体验流程

首页点击「开始摸鱼」→ 首次分步教学 → 正式连续波次 → 三次受击 → 成绩单 → 再来一局／返回首页。

教学按实际操作推进：拖动猫猫至少 36 逻辑像素，逐条拾取附近的绿色小鱼，五格满后点击右上角头像。当前目标有光圈提示，底部只显示当前步骤，可以跳过。教学期间不刷工作弹幕、不受伤、不计时、不计分；释放护盾后直接进入正式波次。完成或跳过会记住状态，后续开局直接游戏；首页「操作教学」可重新体验。

头像单击在抬手时生效；蓄力不足、拖出头像或取消触摸都不会释放。头像可由第二根手指单独操作，第一根手指继续拖动。五条鱼换 3 秒护盾，外圈保持绿色五格蓄力和护盾倒计时；旧双击和空格快捷键保留。

音效覆盖按钮、拾鱼、蓄满、放盾、受击、换波、结算七种事件。短音由 `scripts/generate-sfx.mjs` 确定性生成，保存为 `assets/art/audio/*.wav`，总计约 87 KiB，无外部音频依赖。事件经过服务层播放，重复音有间隔限制；首页、暂停页和结算页可关闭，偏好保存在本机。当前提供音效，没有背景音乐。

成绩单展示动画分数、评级、首局／新纪录／与个人最佳的距离、摸鱼时长、抵达波次、最高连击、穿缝与甩脱次数。下一局目标依据护盾使用、存活时间和最佳成绩生成。只在本局结束时存档一次，点击明确的按钮重开或返回首页，避免误触丢失成绩。

## 实现位置

| 文件 | 内容 |
| --- | --- |
| `assets/scripts/model/GameExperience.ts` | 教学状态、本地存档格式、结算与下一局目标 |
| `assets/scripts/PlatformServices.ts` | Cocos 本地存储与音效播放；核心逻辑无 `wx.*` |
| `assets/scripts/GameInterface.ts` | 运行时首页、暂停、分步提示与成绩单 |
| `assets/scripts/GameMain.ts` | 输入、双指头像操作与事件连接 |
| `assets/scripts/model/GameModel.ts` | 练习保护与成功拾鱼事件 |

存储键为 `off-work.progress.v1`，使用 Cocos `sys.localStorage`。保存教学完成、音效开关、最佳分数、最长时长、最高波次和局数；缺失、损坏或不可用的存储不会阻止游戏。记录限本机，没有账号或云同步。
