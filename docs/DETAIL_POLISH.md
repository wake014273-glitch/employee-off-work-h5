# 拾鱼、挡伤、恢复倒计时与弹幕辨识

日期：2026-10-12。实现用户确认的第 1、2、3、5 条细节方案，沿用确认版美术、现有身体碰撞和连续波次规则。

后续调整：满格保留小鱼已按用户要求撤销，恢复满格仍然消耗小鱼；教程与弹幕眼神的最新行为见 `LIGHT_TUTORIAL_AND_EYES.md`。2026-10-15 已删除文件夹缺口两侧的描边提示，文件夹固定在其他工作弹幕与资源点下层，见 `MENU_ART_IMPLEMENTATION.md` 的最新修订。以下保留本轮实施时的记录。

## 交互与画面

1. 拾鱼成功后生成绿色飞光，沿弧线飞向头像外围对应的蓄力格，到达时该格闪亮。能量即时增加 20；满 100 时不消耗场上的鱼，护盾生效期间也不拾鱼。多条鱼同时接触时只消耗补满能量所需的数量。
2. 真正受伤时猫猫短暂压缩，新增的工作负荷格弹跳，并保留原红闪与受伤音。护盾挡住实际身体碰撞时，碰撞方向产生向外扩散的绿色弧线，播放更短、更轻的独立挡伤音，不增加工作格、不清弹、不触发受伤动画。持续重叠时反馈最多约每 0.22 秒一次。
3. 手动暂停或切到后台后，点击继续显示 3–2–1。计分、游戏时长、弹幕、拾鱼、护盾剩余时间及场内特效冻结，倒计时结束后继续。返回前台保持暂停；再次隐藏或点击暂停取消未完成的倒计时。倒计时期间屏蔽拖动、头像及空格放盾，Esc／暂停按钮可以取消。正常换波没有倒计时或停顿。
4. 红消息真正开始追踪后，增加短尾迹并放大 8%；结束追踪后恢复。紫需求表实际转向后按转向方向轻微倾斜 0.26 秒；转向前没有预告。文件夹墙只描亮实际缺口两侧的内边缘，不在场上预告尚未出现的墙，不改变缺口或碰撞尺寸。

## 实现

- `GameModel.ts`：满格拾取条件、受限频率的挡伤事件、真实转向反馈状态和只读墙体访问。
- `GameExperience.ts`：独立恢复倒计时，忽略后台帧与无效时间，限制长帧跳跃。
- `GameMain.ts`：集中绘制尾迹、缺口和挡伤，复用八个拾鱼飞光槽；暂停、后台、重开和首页统一清理输入与反馈。弹幕继续集中更新并复用精灵。
- `FinalArtHud.ts`：每格独立的到达闪亮与工作格动画，工作负荷外框尺寸不变。
- `GameInterface.ts`：恢复倒计时独立卡片。
- `PlatformServices.ts` / `generate-sfx.mjs`：新增确定性生成的 `block.wav`，音量 0.35，受伤音 0.65。声音通过 Cocos 服务层播放。

所有画面由现有 TypeScript 创建，场景、Prefab 与 UUID 由 Creator 维护，没有手改 `.meta`、`.scene` 或 `.prefab`。没有广告、登录、后端或新增微信专有 API。
