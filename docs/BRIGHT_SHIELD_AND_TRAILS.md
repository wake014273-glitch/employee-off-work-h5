# 护盾金光、设置齿轮与移动拖尾

本页记录上一版残影拖尾；当前根据参考视频改成连续渐细光带，见 [第三种拖尾调整](PARTICLE_TRAIL_REFERENCE.md)。护盾与设置颜色沿用本页方案。

本次按用户反馈调整上一版护盾表现。护盾释放后的头顶进度条保持原来的青蓝填充和浅绿色高光，按剩余免疫时间连续退空；仍使用共同的 3 秒护盾时长，进度条变空、金光消失和免疫结束同步。角色下方不显示横幅。

金光轮廓增强为三圈、每圈八个方向的透明遮罩，共 24 个复用精灵。外圈扩大至约 15～18 个设计像素，内圈增加奶油色亮边；保持 1.5 秒呼吸变化。释放前 0.45 秒额外加强轮廓，并显示扩散光环和星芒，之后回到持续金光。轮廓跟随猫猫动画、尾巴镜像和弹簧形变，身体本身保持原色。

设置入口改成八齿圆角齿轮，采用淡紫填色、梅紫描边、奶油中心与浅紫高光，沿用原有圆框和设置交互。

移动拖尾沿实际移动路径留下浅色猫猫残影，最多复用 8 个精灵，约 0.24 秒淡出。每个残影保存当时的位置、动画帧、朝向和身体弯曲；左右转向不会翻转旧残影，上下移动也会产生拖尾。停下后自行消失，暂停时冻结，重新开始、返回首页或远距离跳转时清空。护盾期间拖尾使用奶油金色。拖尾只负责渲染，不参与碰撞和位移。

代码入口：`employee-off-work/assets/scripts/FinalArtHud.ts`、`GameMain.ts`、`model/PlayerTrail.ts`。新增拖尾单元测试，Web 与微信回归共享实际运行中的视觉检查，覆盖齿轮颜色、拖尾轨迹、历史朝向、暂停和停止淡出、释放光环及持续轮廓强度。
