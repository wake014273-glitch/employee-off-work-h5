# 教学界面与成功反馈（2026-10-13）

按确认的方案精简三处界面；开场称呼使用“打工喵”。合并练习仍为三个需求表、一条上方中央的小鱼，保留练习保护和正式开局的一格蓄力。

## 文案与界面

开场保留原标题，猫猫上方改为深紫色三行文案：

> 拖动屏幕，带猫猫绕开工作任务。  
> 摸鱼越久，分数越高！  
> 辛苦啦，打工喵，歇一会儿也没关系～

删除开场下方的绿色说明，重新安排文字、猫猫与开始按钮的间距。开场音效开关仍可使用。

练习只保留下方操作提示：

> 任务绕着走，小鱼拿到手！
>
> 拖动屏幕，带猫猫绕开各种工作任务。  
> 捡发光小鱼，给短暂的“工作免疫”攒充能～

移除教学圆圈、方向箭头、手指和跳过按钮，原位置不再有跳过的命中区域。小鱼本身的绿色拾取特效保留。

拾鱼后显示 `GOOD!你学会啦！`，使用与 HUD 协调的 Arial 粗体、深紫描边和暖金填充，搭配六颗星光、文字弹入、小猫跳跃及成功音。庆祝持续约 1.15 秒，期间冻结练习弹幕和操作；清除练习碰撞残留的闪烁，确保猫猫与阴影正常显示。

完成页保留“好耶，摸鱼入门啦！”、“任务来了绕开它，接下来正式开摸！”、猫猫和“开始摸鱼！”按钮。删除下方绿色说明和音效开关，音效开关原位置也不再响应点击。首页、暂停页和结算页的音效控制仍正常。

护盾释放方式在首次蓄满时提示：“双击屏幕或点头像开启护盾，保护自己 3 秒”。教学版本仍为 3，不因文案和视觉更新强制重播已完成的相同流程；首页“操作教学”可随时重播。

## 实现与验证

通过 TypeScript 运行时 UI 实现，没有改动场景、Prefab、资源元数据或最终美术资源。复用现有音效和图形组件，没有为每颗工作弹幕增加独立更新组件。

验证日志保存在 `employee-off-work/temp/qa/cat-guide-*`，完整网页和微信报告为 `web-result.json` 与 `wechat-result.json`。检查三行开场文案、绿色说明隐藏、无辅助图形、无跳过入口、实际拖动拾鱼、成功文字及描边/音效、庆祝时猫猫和阴影显示、完成页隐藏音效控件的命中区域，以及原有暂停、护盾、结算和难度曲线。

- `npm test`：59 / 59 通过。
- `npm run test:soak`：3 / 3 通过。
- TypeScript `tsc --noEmit`：通过。
- `npm run qa`：真实 Chrome 81 / 81 通过，无运行时错误。
- `npm run build:web` 与 `npm run build:wechat -- appid=wxcefa299717fbb2da`：均有 `build Task (<platform>) Finished` 标记，必需产物存在。Cocos CLI 退出码为 36，按构建规则判定成功。
