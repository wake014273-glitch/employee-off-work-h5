# 加载进度遮挡与启动速度修复

源码指纹：`source:587580702cd604d5`。保留现有难度、音效及原画，未手工修改场景、Prefab、资源 UUID。

## 绿色填充末端

原来填充覆盖 827 像素整条轨道，而鱼的移动范围只有 659 像素；超过一半进度后，绿色末端逐渐超过鱼身，到 100% 时从鱼头前方露出。

现在 `loadingBarGeometry()` 统一计算鱼的位置与绿色末端，末端始终落在鱼身不透明区域内部。Cocos 加载页、网页启动封面和微信原生首屏均使用同一几何规则。0%～100% 的全部 101 个位置，逐行检查轨道高度内的端点均位于鱼的轮廓内部；实际像素检查另行覆盖后半程与满格情况。

满格实际截图：[绿色末端位于鱼身内部](screenshots/loading-fish-covered-100.png)。

## 启动等待

- 网页原先使用调试构建，改为正式构建。
- 移除实际未使用的 Spine、DragonBones、物理、视频、地图、粒子与富文本等模块，保留项目使用的 2D、UI、音频、Graphics、Mask 等能力。
- 美术加载从两个工作队列调整为四个，限制并发的同时重叠网络等待；音频仍在关键画面之后加载，不延长进入首页的等待。
- 精简后 Cocos 将微信引擎文件命名为 `cc.js`，修复构建脚本仅识别旧拆分文件名的问题，保留 iOS、Android、开发工具三种新建 document 的触摸初始化验证。
