> 最新数值已于 2026-10-16 调整为困难阶段前 270 秒每 45 秒、之后每 30 秒升档，且 90 秒后每档红 + 紫同屏上限增加 1；参数表以 `WAVE_SYSTEM.md` 版本 2.2 为准。本文件其余部分保留此前曲线的实施和验证记录。

已按本次确认实现：第二阶段不生成追踪消息，其他阶段按新的节奏与分轮加压曲线调整。参数总表见 [WAVE_SYSTEM.md](WAVE_SYSTEM.md)。

- 正式第一阶段 8 秒、第二阶段 16 秒，第三阶段约在第 24 秒开始。
- 第一阶段紫色需求表 1.1 秒刷新，第二阶段 1.5 秒刷新；紫色路线增加经过角色附近的机会，同时保证侧边出生反应距离。
- 第二阶段只用紫色需求表和黄色文件夹，180 像素宽缺口，限制连续缺口的大幅跳变。
- 第三阶段每 20 秒加压、4 秒平滑过渡；前六轮红色间隔 2.5 / 1.8 / 1.3 / 1.0 / 0.8 / 0.65 秒。同时追踪上限 1 / 1 / 2 / 2 / 3 / 3，消息+需求表上限 8 / 10 / 12 / 14 / 16 / 18，缺口 160 / 150 / 140 / 130 / 120 / 110 像素。
- 每轮末尾 2.5 秒减慢新红色和紫色攻击，暂缓新文件夹；既有攻击、移动和鱼的计时保持正常。
- 第三阶段两分钟后继续加压，后期红色最短 0.5 秒、消息+需求表最多 22 颗、缺口最小 96 像素、速度最高 1.45 倍。同时追踪最多 3 颗，防止无限堆叠。
- 新鱼约 1.8 秒开始出现，此后每 4 秒刷新，围绕玩家的可达区域生成，仍需主动移动。教学保留一格、满格消耗鱼和护盾中不能拾取的规则继续适用。
- 顶部显示“工作加码！第 N 轮”，播放已有提示音。20 秒压力升档与原有 60 秒计分波次分开，避免重复奖励或倍率突然膨胀。

## 2026-10-15：缓慢加压与长局空间

原曲线同时提高生成频率、速度及追踪数量，并收紧文件夹缺口；每 20 秒升档使红色解锁后一分多钟就进入高密度。本次将升档间隔延长到 45 秒、过渡延长到 12 秒，末尾喘息延长到 5 秒。

红色初始间隔 3.4 秒，前六轮目标为 3.4 / 3.1 / 2.8 / 2.5 / 2.25 / 2.0 秒；前三分钟最多一颗同时追踪，随后最多两颗。初始速度 1.04 倍、缺口 180 像素；长局速度不超过 1.22 倍，红色最短 1.3 秒，红紫共享上限 16，缺口不小于 144 像素。连续文件夹缺口中心位移限制为 30% 画面宽度。完整参数见 `WAVE_SYSTEM.md`。

前两阶段、红色解锁时间、计分波次、鱼刷新、护盾时长、命中判定及追踪行为保持原规则。自然三分钟和五分钟测试用无敌状态隔离伤害，用于验证生成与追踪预算、连续升档和稳定性；不代表玩家必定存活相同时长。
